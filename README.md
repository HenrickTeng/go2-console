# Go2 建图与导航控制台

浏览器只开在本机：<http://127.0.0.1:8770>。

四个页面用的是建图导航里的常用叫法：

| 页面 | 做什么 |
| --- | --- |
| 在线建图 | 键盘遥控，边走边看三维激光点云。松键就停。 |
| 语义标注 | 在俯视地图上圈地点或禁行区，并命名。玻璃、楼梯可以标成禁行区。 |
| 自主导航 | 在俯视地图上点一个位置或选一个地点，先规划路径，确认后再让狗走。 |
| 任务编排 | 用一句话把地点串起来。例如「先去饭堂，等人，再去教室」。到点会停下，等人确认后再走下一段。 |

启动前先让建图程序跑着（`ros2 launch go2_core go2_start.launch.py`）。控制台自己不会启动建图，也不会在打开页面时让狗动。

```bash
source /home/henrick/go2_slam_ws/setup_go2.sh
cd /home/henrick/go2_slam_ws/go2_console
python3 -m go2_console
```

地图和标注写在 `go2_console/data/`。速度上限 0.3 m/s。急停会停掉遥控、导航和任务。

人不在旁边时不要点「开始前往」或「开始任务」。导航走的是当前栅格上的 A*，会绕开障碍和禁行区，经现有的 `cmd_vel` 发给高层运动接口。这不是 Nav2，教室门口这种窄地方如果规划失败，把禁行区画小一点再试。

办公室第一次建图的栅格、位姿图和标注在 [examples/office](examples/office)。里面有饭堂、教室、玻璃门和杂物堆。`data/` 里还没有地图时，控制台会读这份例子。

建图程序来自本机的 `go2_slam_ws`（slam_toolbox 那套）。这个仓库只有控制台和示例地图，不包含那套建图源码。
