# 办公室示例地图

2026-11-03 在办公室用 Go2 机载激光建的第一张图。狗当时不在图上的固定起点，这份图的原点就是那一次建图启动时脚下的位置。

| 文件 | 内容 |
| --- | --- |
| `map.pgm` `map.yaml` | 栅格地图，控制台用来画区域和规划 |
| `map.posegraph` `map.data` | slam_toolbox 位姿图，下次在同一片地方做定位时用 |
| `semantic.json` | 手动画的区域 |

区域：

| 名称 | 类型 |
| --- | --- |
| 饭堂 | 地点 |
| 教室 | 地点 |
| 玻璃门 | 禁行区 |
| 杂物堆1 | 禁行区 |

控制台在 `data/` 里还没有地图时，会直接读这一份。另存的新地图写到 `data/`，不会改这里的例子。
